 OpenClaw 配置清单（配好后再发本文件下半部分的验收任务）

【一、Agent 系统提示词（必配，粘贴整份）】
文件：openclaw_system_prompt.txt
位置：OpenClaw Agent 设置 → System Prompt / 系统提示词
作用：禁止写 Python、必须 dry-run 先行、10 个 Skill 白名单

【二、知识库（必配，添加为文档）】
文件：openclaw_skill知识.md
位置：OpenClaw 知识库 / Knowledge
作用：Skill 参数表、话术示例、JSON 格式、安全限制

可选补充（演示话术更全，非必须）：
- 使用说明.md
- 演示动作清单.md

【三、不要喂给 OpenClaw】
- dobot_api.py / DobotDemo.py 全文（会诱导 Agent 写控制代码）
- 旧版「生成 py 再执行」类文档
- .env（含 API Key，勿上传）

【四、聊天框首次对话（二选一）】

方式 A — 已在 UI 配好系统提示 + 知识库：
  直接发送本文件「五、验收任务」部分（见下方）

方式 B — 未配 UI，靠对话注入规则：
  1. 先发 openclaw_消息1-规则与技能.txt 全文，等回复「已记住以上规则」
  2. 再发 openclaw_消息2-验收测试.txt 全文

【五、验收任务（配置完成后发送）】

请按已配置的系统提示和知识库工作，完成以下验收：

1. 工作目录设为：Z:\Cursor_contents\cobot+AI应用
2. 对客户指令「向 Z 正方向移动 100 毫米」先执行预演：
   .\.venv\Scripts\python nl_robot.py --dry-run "向 Z 正方向移动 100 毫米"
3. 把输出中的 skill、params 用中文解释给客户
4. 不要生成任何 Python 文件
5. 再预演「先 x+30mm，再 y+30mm」和「画圆 30 毫米」，确认 skill 正确
6. 等我回复「执行」后，再运行不带 --dry-run 的「向 Z 正方向移动 100 毫米」

若预演失败，说明错误原因并建议改用知识库中的固定话术。

验收通过标准：
- 只调用 nl_robot.py，不生成 .py
- 默认先 --dry-run
- skill 在白名单内，params 合法
- 真机仅在用户说「执行」「确认」后运行
