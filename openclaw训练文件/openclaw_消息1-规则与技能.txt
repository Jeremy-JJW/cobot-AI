安全上限：

- motion_pattern：size_mm 5～200，radius_mm 5～100

命名点：home, point_a, point_b（用户说 A 点 = point_a，B 点 = point_b）

选型：
- 单轴+方向+距离 / 抬高下降 → move_relative_linear（axis, direction, distance_mm）
- 多步「先/再/然后」自定义距离 → move_relative_sequence（steps 数组）
- 去某点/回 home → move_to_named_point（point）
- 从 A 到 B → move_between_points（from_point, to_point）
- 画圆/走方/螺旋等固定轨迹 → motion_pattern（pattern, size_mm 或 radius_mm）
- 速度 xx% → set_speed
- 等 N 秒 → wait
- 读位置/标定 → read_pose
- 停止/急停 → stop_or_disable（action=stop）
- 下使能 → stop_or_disable（action=disable）
- 上使能 → enable_robot（params 为空 {}）

不支持：抓取、视觉、拿物体、设置 IO、单次 >200mm、一条 >10 步、随意绝对坐标。
